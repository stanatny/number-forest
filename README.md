# 数感森林

**[🌳 在线试玩：数感森林](https://stanatny.github.io/number-forest/)** · [源代码](https://github.com/stanatny/number-forest)

一个无需安装的中文亲子数学游戏。孩子可以补齐松果、比较多少、找数字规律、合并果篮、沿数线跳跃、成组分装和观察时钟，再从这些操作中发现数量关系。每次探索 10 个小任务，不限时、不排名，可以中途返回地图，之后继续。

面向电脑和 iPad 的浏览器使用，也提供窄屏布局。建议家长先一起探索，再把同样的问题换成积木、水果和家里的钟，观察孩子能否解释自己的想法。

## 现在可以玩什么

| 章节 | 探索内容 |
| --- | --- |
| 松果小屋 | 10 以内分与合，20 以内比较多少、按 `+1`、`+2` 或 `−1` 找数字规律。 |
| 森林补给 | 20 以内加减、凑十与跨十练习、补数，以及数线上向前或向后跳。 |
| 种子花园 | 总数不超过 20 的成组探索：多一组、数总数、找组数；从 `3 × 3 = 9` 发现 `3 × 4 = 12`。 |
| 野餐草地 | 总数不超过 20 的平均分与分装：分给几个人，每人几颗；每袋装几颗，能装几袋。 |
| 滴答树屋 | 整点、半点、混合读时，再看半小时或一小时以后；时针随分钟连续移动。 |

界面采用明亮的森林绘本风格：五张章节插画卡、小松鼠伙伴、可点亮的十步探索路线和有图形提示的操作按钮。首页小松鼠会眨眼、挥手和摆尾，动作之间留有休息；离开首页、切到后台或开启“减少动态效果”时停止。做题时小松鼠会随摆放、提示与答对切换回应；新放入的物体、被点击的伙伴和答案按钮各有短暂动画。装饰与实际计数区分开，操作不需要等待动画结束。给家长的长说明可以展开查看。

各章可以自由选择。提示、操作和答题共用同一组数量。答对时会出现星光、彩纸和松鼠跳跃，完成整章还有一次庆祝；答案与下一步始终可见。特效短暂播放后自动结束，遵循系统的“减少动态效果”设置。答对后突出展示答案与完成反馈；答错后按题型解释数量差异、数列规律、分配情况或时针与分针的位置，也可以听朗读。题干旁始终显示这道题的主要数学关系：未选择时用问号表示要找的数量，选择答案后自动试填；试填数字使用暖白底、深色粗虚线和清晰阴影，旁边保留问号，下方用深色“待检查”小标签区分尚未确认的答案；不使用整条彩色提示横幅，选中的按钮和篮子也使用待检查样式；等号旁保留问号。检查通过才显示绿色勾和完整算式；比较题保留左右篮的位置，数列标出实际缺口，时钟使用时刻与经过的时间。数字下面的短标签对应已有、添来、每篮、篮数、总数等含义，部分场景用相同颜色对应数量。需要时展开“换个写法，看看联系”，观察重复加法、乘法与除法之间的关系；主算式不需要展开。主式和展开后的相关算式同步试填，换答案立即更新；比较题高亮所选篮子的数量，比较符号仍待确认；时钟试填选中的中文时刻。点提示或摆放物体不会自动确认试填，平均分还需满足原来的摆放规则。完成任务后还可查看关联算式。每题第一次检查就保留对错，答错后立即显示正确答案和具体原因，可以直接下一题，也可以先订正；订正成功仍保留首次错误，进度条以 × 标记。最后一题答错会停留在解释页，点击“完成这趟探索”后结束；最后一题答对则自动完成整章，在深夜森林舞台上展示专属徽章：星光蓄力、徽章由小变大并沿竖轴交替展示正反面、金色冲击环和亮面扫光，约 4.6 秒后定格。徽章正反面随脚本一起加载并提前解码，领奖时不再请求图片；图片准备完成后才同步启动翻转与星光，失败时也有可见的金色奖章；结算会显示首答正确与错误题数；最后一题的完整主算式直接保留在结果页，尚未订正的题标为正确关系参考，不冒充已经答对，详细讲解可展开查看。五章各有一枚不同的原创徽章，首页可查看收藏；再次完成同章会重新展示该徽章，不重复增加徽章种类。

乘法场景固定使用“每组数量 × 组数”。例如，每篮 3 颗、4 篮，写作 `3 × 4 = 12`；平均分给 4 个小伙伴，写作 `12 ÷ 4 = 3`。先理解场景，再逐渐熟悉算式，不要求先背乘法表。

题目的数量在各题型的合法范围内随机产生，题型按每章的 10 个任务安排交替出现。种子花园的第一题固定为 `3 × 3 → 3 × 4`，野餐草地的第一题固定为 `12 ÷ 4`；时钟先有三道整点、三道半点，再加入混合读时和时间推进。随机不保证去重，也不代表所有数字组合出现概率相同。继续未完成的探索会恢复原题，不重新抽题。

## 打开游戏

直接在电脑或 iPad 浏览器中打开 **[数感森林在线试玩](https://stanatny.github.io/number-forest/)**，无需下载或安装。固定地址为 `https://stanatny.github.io/number-forest/`，可收藏后继续玩。

下载整个仓库并解压，保留 `index.html`、`src/`、`styles/`、`assets/` 的相对位置，在电脑浏览器中打开 `index.html` 即可。游戏不需要安装依赖、构建或启动后端，页面和图形均为本地文件。

也可以在仓库目录运行静态服务器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8000`。在线访问适合直接从电脑或 iPad 打开；下载后的本地文件可离线使用。HTTPS 网站和 localhost 会在首次加载完成后缓存游戏页面、脚本和插画，后续断网仍可打开已缓存的游戏。语音按需下载并缓存，未听过的语句在断网时可能无法播放；这不会阻止做题。缓存不可用或存储空间不足时，游戏仍可在线运行。更新页面和语音索引优先检查网络，缓存随版本更新。

中文朗读使用 Qwen3-TTS 的 Serena 音色预先生成的完整录音，覆盖当前 767 种题干，以及欢迎、通关、鼓励和题型引导。浏览器只下载小型 MP3，不运行语音模型、不调用在线合成服务。题目按钮读完整题干；“听小松鼠”播放鼓励或该题型的方法提示，具体数量的纠错解释仍由画面展示。朗读默认关闭，可点“听题目”开启；离开页面或关闭朗读会立即停止。来源与生成方式见 [语音说明](assets/voice/README.md)。

背景音乐是本项目编写的 112 BPM 原创旋律，以轻快木琴、拨弦、低音和柔和打击乐通过 Web Audio 实时合成，不下载外部音频。音乐默认关闭，可随时开关；朗读时平滑降低伴奏音量，页面进入后台时自动暂停。

## 练习记录

记录保存在当前浏览器中。v0.7 起每道题第一次点击“检查答案”就固定记录为首答正确或首答错误：

- 答错会立即显示哪里不对及正确答案，允许继续下一题，不要求先改对；后续订正只增加“错题中已订正”，不会减少错误数、增加首答正确数或重复增加题数。
- 点过提示但第一次提交正确，仍记为首答正确。平均分如果已经开始摆放，还需全部分完且每份一样多；数字正确但摆放未完成时会明确说明，按整道任务首答未通过计入错题。
- 结算显示这一轮的首答对错，家长小记显示累计首答正确、首答错误、已订正、首次正确率与完整探索次数。每章仍为 10 道题，徽章表示完成探索，不表示全对。
- 最后一题答错后先查看解释，点击完成后才保存通关；答对时直接保存。记录与徽章不依赖动画播放结束。

“首答用时”累计每题第一次检查前的前台时间，包括读题、思考、摆放和主动查看提示。首次检查后暂停，解释和订正、地图及后台停留不计入。它不能直接当作口算速度。旧版直到答对的 10 题练习用时单独保留，不与新版首答最快记录混合比较。

旧版完成记录和徽章保留，但不能根据“借助提示或修正后完成”推断首答对错，因而单列为“旧版已完成 · 未评分”，不计入正确率。旧版未完成的一轮仍可继续：已完成的题保留为历史未评分；当前题若已经提交过错误答案，会保留这次错误并且只计一次。混合旧进度的一轮用时归入旧版练习口径。

首页“我的森林徽章”旁和“家长小记”中都有“重置通关记录”。确认后会清空当前浏览器的徽章、通关次数、用时、练习统计与未完成进度；已经打开的新版游戏标签页也会回到首页，避免旧进度再次写入。取消确认不会改变记录。重置不删除游戏与语音缓存。

不同设备、浏览器和网址不会共享记录；本地文件与线上网站也分别保存。清除浏览器数据会清除记录。游戏没有账号、服务器端成绩库或统计上报。

未完成的探索会自动保留。刷新后可在首页选择“继续刚才的……”回到同一题，恢复选项、提示和内置场景的摆放状态；首次结果与订正状态不会因刷新丢失，也不会重复计数。每个浏览器保留一轮未完成进度，开始新探索会替换它。

v0.2 升级到每轮 10 题后，旧版已完成的任务和探索次数仍累计保留。原来 5 题一轮的用时另行保留，不参加新版 10 题的最快用时比较。由于题型和出题规则改变，旧版未完成的一轮不能接着恢复；首页会提示从新的一轮开始，已经完成的记录不受影响。

## 开发与扩展

- `src/core.js`：章节注册、题目生成、答案规则与数学关系；同时支持浏览器脚本和 Node.js 测试。
- `src/assessment.js`：冻结首次作答结果、汇总首答对错并恢复旧版进度；与是否完成订正分开。
- `src/formulas.js`：把各题型的数量关系转为带未知量、单位标签与关联写法的结构；区分未选、试填与已确认的值，不改变答案判定。
- `src/feedback.js`：纯反馈规则，区分答案单位、数量差异、分配状态、数字规律与时间变化，不修改练习状态。
- `src/views.js`：可选的场景渲染器注册接口。
- `src/effects.js`：普通答题庆祝粒子，以及限定在领奖舞台内的通关流星、冲击环与星群；播放结束、离开页面或进入后台时清理。
- `src/audio.js`：原创背景音乐的 Web Audio 合成、朗读时降低音量、开关与后台暂停。
- `src/speech.js`、`assets/voice/`：完整中文题干与引导录音、按需准备、播放与取消。
- `src/home-motion.js`：首页松鼠动画的可见性与减少动态效果控制。
- `src/badge-art.js`：徽章原图的内嵌副本与解码准备，由 `node scripts/build-badge-art.mjs` 生成。修改 `assets/badges/` 后需重新生成。
- `src/cache.js`、`sw.js`：静态游戏与已播放语音的离线缓存，支持 GitHub Pages 子路径与音频分段请求。
- `src/app.js`：页面状态、内置操作场景、答题反馈和家长记录。
- `styles/main.css`、`styles/playful.css`、`styles/badges.css`、`styles/formulas.css`、`styles/assessment.css`、`assets/`：基础样式、绘本界面与有限互动动画、通关舞台；`assets/playful/` 内含原创森林插画及小松鼠的三种姿态，`assets/badges/` 内含五枚原创 SVG 徽章及共用的森林纹章背面。
- `tests/`：题目生成、数学不变量与边界测试。
- `scripts/build-site.mjs`：按白名单生成发布目录及版本信息。

新增章节可复用内置场景，也可以注册独立的操作界面；详见 [章节扩展说明](docs/EXTENDING.md)。

安装 Node.js 后运行：

```bash
node --test tests/*.test.cjs
```

或运行 `npm test`。测试没有第三方依赖，不需要 `npm install`。浏览器验收还需真实操作各章、提示、纠错、结束、刷新和窄屏布局。教学设计仍需通过亲子试玩，检查兴趣、理解及屏幕外迁移。

## GitHub Pages

源码保留在 `main`，网站从 `gh-pages` 分支的根目录发布。仓库的 **Settings → Pages → Build and deployment → Source** 选择 **Deploy from a branch**，分支选择 **gh-pages**，目录选择 **/ (root)**。配置方式参考 [GitHub 官方发布源说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

发布前运行测试和打包：

```bash
npm test
npm run build
```

`npm run build` 调用 [发布脚本](scripts/build-site.mjs)，生成 `.local/site`。其中仅包含 `index.html`、`src/`、`styles/`、`assets/`、`sw.js`、`LICENSE`、`.nojekyll` 和 `version.json`；版本信息用于核对线上内容。将这个目录的内容提交并推送到 `gh-pages` 根目录后，GitHub Pages 更新网站。页面使用相对路径，支持仓库子路径部署；本地直接打开游戏的方式不变。
